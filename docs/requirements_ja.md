# 要件定義: 現象ごとに切り替えられる格子シミュレーション

状態: 草案（2026-11-03）。合意後に実装へ進みます。

## 1. 背景と目的

これまで MultifieldInflationLattice（以下「本体」）と MFILHybridChecks（以下「検証」）で、
次のような異なる実行形式を個別のスクリプトや設定で使い分けてきました。

| 区分 | これまで使った形式 |
|---|---|
| 初期条件 | 箱内全モードに Bunch-Davies 揺らぎ／初期に小スケールを切る／開始時刻の違い（論文の N = −2.13 と N = 0） |
| 揺らぎの供給 | なし（古典格子のみ） |
| 格子点の結合 | 勾配項あり |
| 時空 | 格子平均から自己無撞着に決める FLRW。計量揺らぎなし |
| ζ の推定 | 一様密度面への δN、η_r = −2 面での決定論的推定（ホライズン横断時と k_σ 横断時のスナップショットから）、ノイズ平均、線形 `ζ_lin` |
| 後処理 | 低周波カット、格子運動量でのスペクトル、論文の N_k への換算 |
| 理論との比較 | 計量なし／計量ありの MS 方程式、スローロール式、1 点の BD-δN |

ハイブリッドインフレーション（arXiv:2603.04850 の Fig. 3）の検証では、次のことが分かりました。

- MFIL の P_ζ は、各格子で分解できる最小スケールに向かって単調に増えます。
  同じ N_k での値は、分解能を 2 倍にするとおよそ半分になり、収束しません。
- 総分散 var ζ ≈ 0.38 だけは、箱の大きさにも分解能にも依存しません。
- 論文は ψ = 0 から始め、k_σ = σaH を越えたモードにだけ ψ のノイズを入れます。勾配項は入れず、
  格子段階の後のノイズを実現ごとに平均して、格子 1 マスのスケールで粗視化しています。
  MFIL にはこれに当たる処理がありません。

このように、同じ模型でも「どの実行形式で計算したか」で結論が変わります。本要件の目的は次の 2 点です。

1. 実行形式を独立した軸に分解し、設定ファイルで切り替えられるようにする。
2. 検証する現象ごとに、軸の組み合わせ・比較対象・受け入れ基準を「プリセット」として固定し、
   誰が実行しても同じ検証になるようにする。

## 2. 範囲

対象:

- 平坦 FLRW 上の多成分正準スカラー場の 3 次元周期格子
- 時空は格子平均から自己無撞着に決める FLRW。勾配なしの形式では格子点ごとの局所 Friedmann（§4 A3）
- 曲率揺らぎは δN（非摂動）と線形推定量

範囲外:

- **計量揺らぎ。** 本コードの δN が物理的に正しいのは ε ≪ 1 の場合に限られます。
  2 場 quadratic（ε ~ 10⁻²）では、計量なしの理論は計量ありの理論の約 0.71 倍でした。
  ハイブリッド（ε ~ 10⁻¹⁶）では無視できます。この制約は文書と実行時の警告で明示します（FR-11）。
- 数値相対論、重力波、再加熱後の発展

## 3. 役割分担

| 本体（MultifieldInflationLattice） | 検証（MFILHybridChecks） |
|---|---|
| 計算の中身: 初期条件、ノイズ注入、勾配の有無、終了面、δN、スペクトル | プリセット（設定テンプレートと実行スクリプト） |
| ポテンシャル（ハイブリッドを本体へ移す。現在はパッチ） | 理論値の計算（MS 方程式、スローロール、1 点確率的 δN） |
| 出力形式とメタデータ | 論文との比較図、受け入れ判定、報告書 |
| 単体・回帰試験 | 遠隔実行用スクリプト（準備、起動、状態確認） |
| 描画（`plotting/` の MFILPlots） | 現象固有の図（Fig. 3 形式など） |

原則: 本体は特定の論文や模型に依存しない機能だけを持ちます。検証は本体の公開 API と CSV 出力だけを使い、
本体へパッチを当てません。現在のハイブリッド用パッチは解消します（FR-10）。

## 4. 切り替えの軸

各軸は独立に選べます。**新しい設定節がない既存の設定は、現在と同じ挙動を保ちます**（NFR-1）。

### A. 力学

| ID | 選択肢 | 現状 |
|---|---|---|
| A1 | 勾配項あり（7 点 Laplacian）、格子平均から自己無撞着に決める FLRW、共形時間 | 実装済み |
| A2 | 勾配項あり、背景を外部から固定（試験用） | 未実装 |
| A3 | 勾配項なし（分離宇宙）。格子点ごとに局所 Friedmann、時間は e-fold | 未実装（検証側の `mini_stolas.jl` に試作あり） |

A3 では各格子点が自分の H を持つので、共通の共形時間ではなく e-fold を時間に使います。

### B. 初期条件

| ID | 選択肢 | 現状 |
|---|---|---|
| B1 | 全モードに Bunch-Davies 揺らぎ（有効質量の有無を選択） | 実装済み |
| B2 | 指定した k 範囲だけ Bunch-Davies。k の単位は格子 index または k/aH | index 指定のみ実装済み |
| B3 | 揺らぎなし（一様）。場ごとに指定 | 未実装 |
| B4 | チェックポイントから再開 | 実装済み |

### C. 揺らぎの供給（確率的ノイズ）

| ID | 選択肢 | 現状 |
|---|---|---|
| C0 | なし | 実装済み（既定） |
| C1 | k_σ = σaH を越えた殻にガウスノイズを注入 | 未実装 |

C1 の設定項目:

- σ、注入する場、殻の許容幅（論文は ±1/2）
- 振幅: 質量なし H/2π、または有効質量ありのモード関数
- 場の値だけか運動量にも入れるか
- k > k_σ の成分を射影で消すかどうか
- 注入を止める条件: Nyquist または N_L/4 に達したとき
- ノイズ用の乱数 seed（場の初期化の seed とは別系統）

### D. 終了面と ζ の推定

| ID | 選択肢 | 現状 |
|---|---|---|
| D1 | 一様密度面への δN | 実装済み |
| D2 | η_r 面（値は設定で指定）への δN | 検証側に実装（`paper_deltaN.jl`） |
| D3 | 格子段階の後、格子点ごとに独立なノイズを η_r まで入れ、初通過時間を実現数 R で平均 | 検証側に実装（ノイズ平均の推定量） |
| D4 | 線形 `ζ_lin` | 実装済み |

### E. 観測量と後処理

- スペクトルは格子有効運動量を既定にします（`n_eff = (N/π)√Σ sin²(πnᵢ/N)`）。
  連続の k³ を使うと、高い n で約 1.2 倍に過大評価されていたためです。
- 殻の採用条件（`(s + 1/2) ≤ N_L/4` など）と低周波カットは、解析時の引数で指定します。
- 背景を参照し、箱の大きさから論文の N_k へ換算します（開始時刻によらない式）。

## 5. プリセット（検証する現象）

| ID | 現象 | 軸の組み合わせ | 比較対象 | 時期 |
|---|---|---|---|---|
| **P1** | **線形検証** | A1, B1, C0, D1/D4 | 計量なし MS 方程式（主）、計量あり MS 方程式、スローロール式 | **第 1 段階** |
| P1h | ハイブリッドの線形段階の検証 | A1, B1, C0 | ψ の質量でのモード方程式（N ≲ 6） | 第 1 段階 |
| P2 | STOLAS の再現 | A3, B3, C1, D2+D3 | 論文 Fig. 3、式 (3.6) の当てはめ | 第 3 段階 |
| P3 | 勾配の効果 | A1, B3, C1, D2+D3 | P2 の結果 | 第 3 段階 |
| P4 | タキオン的成長 | A1, B2（不安定モードのみ）, C0 | 線形のタキオン成長率 | 未定 |

P1h は、ハイブリッドで「初期条件の実装に誤りがないか」を確定させるための検証です。

### P1 の受け入れ基準

これまでの 64³ 2 場 quadratic 検証の実績（括弧内）をもとに定めます。

| 項目 | 基準 |
|---|---|
| モード毎の場の振幅 vs 計量なし MS | 最大相対差 < 1 %（0.65 %） |
| 殻平均 P_I の比 | 0.97〜1.03（0.980〜0.998） |
| 規格化した残差（pull）の rms | 0.9〜1.3（1.04〜1.20） |
| 背景 H（格子の真空エネルギーを輻射として含めた ODE と比較） | 相対差 < 10⁻⁶（3×10⁻⁷） |
| 終了時の MFIL δN vs 同じ実現の線形 δN | 比 1 ± 10⁻³（0.99997） |
| 終了時の MFIL δN vs 計量なし MS のアンサンブル | 比 1 ± 0.03（0.987） |
| 計量あり理論との比（参考値。合否に使わない） | 記録のみ（0.71、計量の効果） |

## 6. 機能要件

- **FR-1** 軸 A〜D を TOML の設定節で選べること。不正な組み合わせは run ディレクトリを作る前に
  `validate_config` が拒否すること（例: 全場を B3 にして C0 を選び、揺らぎがまったくない設定）。
- **FR-2** B3: 場ごとに揺らぎなしを指定できること。
- **FR-3** B2: k の範囲を格子 index でも k/aH でも指定できること。
- **FR-4** C1: §4 C の項目をすべて設定できること。ノイズの統計（殻ごとの分散）が設定値と一致することを単体試験で確かめる。
- **FR-5** A3: 局所 Friedmann と e-fold 時間で発展させること。C1 なしでは、全格子点が一様な場合に
  背景 ODE と一致すること。
- **FR-6** D2, D3 を本体へ移すこと（現在は検証側）。D3 の実現数と η_r の値を設定できること。
- **FR-7** メタデータに選んだ軸とプリセット名を記録すること。
- **FR-8** スペクトルは格子有効運動量を既定とすること。
- **FR-9** チェックポイントに、ノイズ用乱数の状態と注入済みの殻を含めること。
- **FR-10** ハイブリッドのポテンシャルを本体のポテンシャル登録に加え、検証側のパッチを廃止すること。
- **FR-11** 実行中の ε_H の最大値を記録し、閾値を越えたら「計量揺らぎを無視した δN の適用範囲外」と警告すること。
- **FR-12** 検証側は、プリセット名を 1 つ指定すれば、計算・理論値・比較図・受け入れ判定（TOML と図）まで
  一括で実行できること。
- **FR-13** MFILPlots は、新しい出力（ノイズ注入の履歴、η_r 面の δN）があれば図にすること。

## 7. 非機能要件

- **NFR-1 後方互換。** 新しい設定節を持たない既存の設定は、現在と同じ結果を出すこと。
  `deterministic_reductions = true` ではビット単位で一致させる。既存の回帰試験を維持する。
- **NFR-2 再現性。** 同じソース・Manifest・設定・seed なら、スレッド数によらず同じノイズ列になること。
- **NFR-3 性能。** C0 の既存経路は 10 % 以上遅くしないこと。C1 の追加コストは格子段階の 20 % 以内を目標にする。
  参考: 128³ ハイブリッドで格子段階 約 3.2×10⁴ s、δN 約 3.2×10⁴ s（24 スレッド）。
- **NFR-4 遠隔実行。** 長時間の計算は SSH の切断で止まらないこと（`setsid nohup`）。状態ファイルで進行を確認でき、
  途中から再開できること。認証は利用者が行い、スクリプトはパスワードを扱わない。
- **NFR-5 試験。** 各軸に単体試験を置く。各プリセットに小さい格子での短い試験（CI 用）と、
  本番規模の受け入れ試験を置く。
- **NFR-6 文書。** 各軸の物理的な意味と適用範囲を README に記載する。各プリセットの結果は、日付付きで検証側に保存する。
